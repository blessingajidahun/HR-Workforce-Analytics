# HR Workforce Analytics Dashboard
### Strategic HR Insights for Data-Driven Decision Making
## Executive Overview
This project presents a fully interactive HR Analytics Dashboard built in Power BI to transform workforce data into strategic insights for HR leadership.
The dashboard moves beyond descriptive reporting and focuses on answering high-impact business questions around workforce structure, compensation equity, recruitment performance, and geographic distribution.
Designed with executive decision-making in mind, this solution demonstrates how HR analytics can support organizational planning, budget allocation, and talent acquisition strategy.
## Business Context & Problem
HR departments often operate with siloed data, making it difficult to answer questions such as:
- Are we over- or under-investing in certain departments?
- Which recruitment channels generate the best hiring volume?
- Does workforce demographic composition align with company goals?
- Are compensation structures balanced across business units?
- Where is our workforce geographically concentrated?
## Tools Used
- PowerBI Desktop
- Power QUery

This dashboard was built to centralize HR metrics into a single decision-support system.

## Compensation & Departmental Analysis
### Average Salary by Department

| -------------------- | ---------- |

### Key Insights
- Executive compensation is 3.6x higher than Production.
- Technical departments (IT & Software Engineering) command above-average salaries.
- Production salaries fall 13% below company average.

This analysis supports:
- Budget reallocation discussions
- Compensation benchmarking
- Internal pay equity assessments
